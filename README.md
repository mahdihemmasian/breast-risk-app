# ارزیابی هوشمند خطر سرطان پستان (Android / iOS)

نرم‌افزار آفلاین پیش‌بینی خطر سرطان پستان بر پایه **مدل Gail (NCI BCRAT)**، غربالگری ژنتیکی **FHS-7** و عوامل سبک زندگی، با خروجی **گزارش PDF فارسی** (هشدارها، توصیه‌های پزشکی، برنامه غربالگری و برنامه غذایی ۷ روزه).

## معماری

```
www/                  ← کل برنامه (HTML/CSS/JS بدون وابستگی، کاملاً آفلاین)
  js/gail.js          ← موتور Gail: پورت خط‌به‌خط پکیج رسمی BCRA نسخه 2.1.2 (NCI)
  js/models.js        ← FHS-7، ضرایب سبک زندگی، طبقه‌بندی خطر، توصیه‌ها، برنامه تغذیه
  js/report.js        ← سازنده PDF (رندر فارسی روی Canvas + نویسنده PDF داخلی)
  js/app.js           ← پرسشنامه هوشمند تطبیقی (سؤالات شرطی + اعتبارسنجی)
capacitor.config.json ← تبدیل به اپ نیتیو اندروید و iOS
.github/workflows/    ← ساخت خودکار APK و IPA در GitHub
tests/                ← تست موتور Gail و تست end-to-end
```

## مدل‌ها و وزن‌دهی

| مؤلفه | روش | منبع |
|---|---|---|
| خطر ۵ ساله و تا ۹۰ سالگی | مدل Gail 2 / BCRAT: سن، سن قاعدگی، سن اولین زایمان، تعداد بیوپسی، هیپرپلازی آتیپیک، بستگان درجه یک (+ اثرات متقابل) | Gail 1989؛ BCRA R v2.1.2 |
| مقایسه با میانگین | خطر زن هم‌سن با RR=1 (نرخ‌های SEER 1992-96) | BCRAT |
| خطر ارثی | پرسشنامه FHS-7 (یک پاسخ مثبت = ارجاع ژنتیک) | Ashton-Prolla 2009 |
| برآورد ترکیبی | ضرب نسبت‌های خطر متاآنالیزها در هازارد Gail: BMI پس از یائسگی، الکل، فعالیت، دخانیات، شیردهی، HRT، سن یائسگی، تراکم پستان (سقف ×۰٫۵ تا ×۳) | WCRF 2018، Lancet 2019، ... |
| طبقه‌بندی | ۵ ساله ≥۱٫۶۷٪ «بالاتر از متوسط»؛ ≥۳٪ یا طول عمر ≥۲۰٪ «بالا» | NSABP P-1، USPSTF 2019، ACS |
| موارد خارج از مدل | سابقه سرطان/DCIS/LCIS، رادیوتراپی قفسه سینه <۳۰ سالگی، جهش BRCA ← ارجاع مستقیم | BCRAT |

صحت پیاده‌سازی: نسبت‌های خطر با خروجی منتشرشده پکیج BCRA تطبیق داده شده (`npm test`).

## ساخت فایل نصبی

### روش ۱ — بدون نصب ابزار (پیشنهادی): GitHub Actions
1. پوشه را در یک مخزن GitHub آپلود کنید (push).
2. تب **Actions** ← «Build Android APK» اجرا می‌شود ← فایل `app-debug.apk` را از بخش Artifacts دانلود و روی گوشی نصب کنید (اجازه «نصب از منابع ناشناس» لازم است).
3. برای iOS: «Build iOS» را دستی اجرا کنید. خروجی IPA امضا نشده است؛ برای نصب روی آیفون باید با حساب Apple Developer در Xcode امضا شود (یا از TestFlight استفاده کنید). محدودیت امضای iOS از طرف اپل است.

### روش ۲ — روی کامپیوتر خودتان
پیش‌نیاز: Node.js 20+، Android Studio (برای اندروید)، Mac + Xcode (برای iOS).
```bash
npm install
npx cap add android && npm run icons && npm run apk      # خروجی: android/app/build/outputs/apk/debug/app-debug.apk
npx cap add ios && npx cap sync ios && npm run open:ios  # در Xcode: Signing ← Product ▸ Archive
```
برای انتشار در Google Play/کافه‌بازار نسخه release را با keystore امضا کنید (`npm run apk:release`).

### روش ۳ — نصب فوری به‌صورت PWA
پوشه `www` را روی هر هاست HTTPS قرار دهید ← در Chrome اندروید «Add to Home screen» و در Safari آیفون «Share ▸ Add to Home Screen». برنامه آفلاین کار می‌کند.

## فونت (اختیاری)
برای ظاهر یکدست‌تر، فایل `Vazirmatn-Regular.ttf` را در `www/fonts/` بگذارید و در `css/app.css` یک `@font-face` با نام `Vazirmatn` اضافه کنید؛ گزارش PDF هم خودکار از آن استفاده می‌کند.

## محدودیت‌ها و ملاحظات
- این نرم‌افزار ابزار غربالگری و آگاهی‌بخشی است، نه تشخیص. پیش از انتشار عمومی، بازبینی توسط متخصص پستان/انکولوژیست و در صورت نیاز مجوز وزارت بهداشت (نرم‌افزار سلامت) توصیه می‌شود.
- Gail با داده زنان آمریکایی ساخته شده؛ مطالعات ایرانی قدرت تفکیک متوسطی گزارش کرده‌اند. کالیبراسیون با نرخ بروز سن‌ویژه ایران (ثبت سرطان کشوری) گام بعدی پیشنهادی است — ساختار `LAMBDA1` در `gail.js` برای جایگزینی آماده است.
- مدل‌های Tyrer-Cuzick (IBIS) و BOADICEA به‌دلیل پیچیدگی/مجوز پیاده نشده‌اند؛ برای سابقه خانوادگی قوی، برنامه ارجاع به متخصص را توصیه می‌کند.
- اطلاعات فقط روی دستگاه (localStorage) ذخیره می‌شود و به هیچ سروری ارسال نمی‌شود.
