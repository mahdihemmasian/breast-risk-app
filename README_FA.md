# مبدل DICOM به JPEG  (DICOM to JPEG Converter) – نسخه 1.0.0

نرم‌افزار ویندوزی برای تبدیل تصاویر پزشکی DICOM (ماموگرافی، رادیوگرافی، CT، MRI، سونوگرافی و …) به JPEG با بیشترین کیفیت ممکن.

## ویژگی‌ها
- **حفظ رزولوشن اصلی**: هیچ تغییر اندازه یا برشی انجام نمی‌شود.
- **JPEG با بالاترین کیفیت**: جدول‌های کوانتیزاسیون همه ۱ (کیفیت ۱۰۰ واقعی)، بدون زیرنمونه‌برداری رنگ (4:4:4)؛ اختلاف با تصویر ایده‌آل ۸ بیتی حداکثر ۱ تا ۲ سطح خاکستری از ۲۵۵ است و با چشم قابل تشخیص نیست.
- **اعمال درست LUT ها**: Rescale Slope/Intercept، پنجره (Window Center/Width) و VOI LUT ذخیره‌شده در فایل، تا تصویر همان‌طور که در ایستگاه کاری رادیولوژی دیده می‌شود ذخیره شود.
- **MONOCHROME1** (رایج در ماموگرافی) به‌صورت خودکار معکوس می‌شود.
- پشتیبانی از DICOM **فشرده**: JPEG Baseline/Extended/Lossless، JPEG-LS، JPEG 2000، RLE.
- فایل‌های **چندفریمی** (هر فریم یک JPEG جدا)، رنگی (RGB/YBR)، و فایل‌های بدون پسوند (خروجی PACS).
- **نسخه کاملاً بدون اتلاف (اختیاری)**: PNG یا TIFF شانزده‌بیتی کنار هر JPEG با مقادیر پیکسل دقیقاً برابر DICOM – مناسب آموزش مدل‌های هوش مصنوعی.
- DPI فایل خروجی از Pixel Spacing محاسبه می‌شود (اندازه فیزیکی حفظ می‌شود).
- تبدیل گروهی پوشه‌ها (با زیرپوشه‌ها)، چندرشته‌ای، Drag & Drop، پیش‌نمایش، ذخیره مشخصات تصویر در JSON با امکان بی‌نام‌سازی.

## نکته مهم درباره «بدون افت کیفیت»
فرمت JPEG استاندارد فقط ۸ بیت (۲۵۶ سطح خاکستری) نگه می‌دارد، در حالی که ماموگرافی معمولاً ۱۲ تا ۱۶ بیتی است. بنابراین:
- JPEG خروجی همان چیزی است که با پنجره انتخابی روی مانیتور دیده می‌شود، با بالاترین کیفیت ممکن در این فرمت.
- اگر داده خام کامل لازم است (پردازش تصویر، هوش مصنوعی، بایگانی)، گزینه **PNG ۱۶ بیتی** را هم فعال کنید.

## روش نگاشت شدت روشنایی
| گزینه | کاربرد |
|---|---|
| پنجره DICOM | پیش‌فرض؛ همان نمایش دستگاه |
| کل محدوده دینامیک | بدون حذف هیچ بخشی از محدوده شدت |
| پنجره خودکار | کنتراست بیشتر برای فایل‌های بدون پنجره |

## استفاده
- **نسخه نصبی**: `DicomToJpeg_Setup_1.0.0.exe` را اجرا کنید (نیاز به دسترسی مدیر ندارد).
- **نسخه پرتابل**: `DicomToJpeg_Portable.exe` را مستقیماً اجرا کنید (روی فلش هم کار می‌کند). نسخه پوشه‌ای پرتابل (`DicomToJpeg_Portable_Folder.zip`) سریع‌تر باز می‌شود.
- **خط فرمان**:
  ```
  DicomToJpeg.exe --cli D:\Mammo -o D:\Mammo_JPEG --window dicom --lossless png16 --json
  ```
